# AI心理医生 · Claude Code 技能（xiaoxingxinliyisheng）

把 **150 位知名心理治疗师**（罗杰斯、贝克、林内翰、亚隆、萨提亚、森田正马、艾瑞克森、河合隼雄、普罗查斯卡、佩里……）的对话方法与 **150 部心理学名著**的对话智慧，落地为 Claude Code 里一次安全、专业、有温度的心理疏导对话。

> 当前版本：**v0.2.0**（2026-09 更新日志见文末）

> ⚠️ **重要声明**：本技能提供的是情绪支持与自助式疏导，**不是医疗行为**。它不提供精神科诊断、不开药、不替代正规心理咨询与治疗。如果你正处于危机中，请拨打全国心理援助热线 **12356**，或前往就近医院急诊。

## 1. 这个项目解决什么问题

直接向通用 AI 助手倾诉烦恼时，常见的问题是：

- **廉价安慰**："别想太多""看开点""加油"——让人更孤独；
- **审问式连环提问**，一次抛出五六个问题；
- **急于给建议**，用户还没感到被听见就被灌输解决方案；
- **忽略危机信号**，对自伤/自杀念头轻描淡写地带过；
- **创伤话题处理不当**，主动引导回忆创伤细节，造成二次伤害。

本技能把专业心理咨询的**对话纪律**写进 Claude Code 的技能提示词，并配套一个可按需加载的治疗师档案库：

| 内置资产 | 规模 | 位置 |
|---|---|---|
| 心理治疗师档案 | 150 位（第 1–50 位经典核心 + 第 51–100 位扩展补充 + 第 101–150 位动机科学/依恋情绪/积极心理/儿童创伤养育/亚洲本土学者），每份含流派身份、代表著作、治疗过程、对话风格、标志性技术（含示例问句）、AI 角色扮演要点 | `references/` |
| 心理学名著整理 | 150 部（书名、作者、核心内容、对 AI 对话的借鉴点，按 16 大类编排） | `builder/data-books.js`、`builder/data-books2.js` 与 `docs/` 源文档 |
| 对话技术速查 | 12 种（情感反映、六级验证、苏格拉底提问、刻度问句、外化命名……） | `SKILL.md` |
| 委婉化 + 具体化对话准则 | 12 条软垫句式与落地规则（试探性开场、三明治反馈、原话引用、微行动处方……） | `SKILL.md` 第 1 节 |
| 心理评价报告 | 触发语、生成规则（只写对话内证据、先优势后困扰、风险优先）、七段式报告模板 | `SKILL.md` 第 7 节 |
| 深度回应模式 | 对等深度原则（用户大段自我剖白时启用）：开场承接 → 分主题梳理（原话为证＋"你不是X，而是Y"式善意重构）→ 非标签化画像 → 轻柔转化提问与转介 → 回应核心渴望；附示范片段 | `SKILL.md` 第 8 节 |
| 议题→流派适配表 | 12 类高频议题（情绪低落、焦虑、原生家庭、恋爱婚姻、意义感/空心病、中年转折、讨好、拖延、强迫、创伤……） | `SKILL.md` |
| 危机响应流程 | 触发信号、询问方式、中国大陆求助热线 | `SKILL.md` |

整个技能**只有提示词和 Markdown 资料，没有任何代码依赖**，核心约 100 KB 文本。

## 2. 主要功能

1. **默认人设（开箱即用）**：一套"风格配方"——罗杰斯式共情做底座、焦点解决做导航、CBT 工具做方法库、DBT 六级验证做情绪安全网、森田/ACT 做行动处方、存在主义视角用于意义议题。
2. **委婉化 + 具体化的说话方式（v0.2.0 新增）**：断言前先垫试探句、不贴标签、三明治式反馈、邀请式提问；同时每个回复必须落到一个具体锚点（原话引用、具体场景或当天可做的微行动），杜绝空话式安慰。
3. **心理评价报告（v0.2.0 新增）**：用户说"给我做个评估/心理评价报告"时，生成一份非诊断性的七段式心理观察小结——只引用对话内的原话证据、先写优势与资源、含风险筛查与"何时该就医"清单；信息不足时先补问而不是硬编。
4. **深度回应模式（v0.2.0 新增）**：用户一次写下大段、多层面的自我剖白时，以与之对等的深度回应——分主题梳理（每个主题都引用原话作证据）、"你不是X，而是Y"式善意重构、非标签化画像、收尾的轻柔转化提问与具体转介建议；让"被认真读完"本身成为一次疗愈体验。
5. **会话流程骨架**：开场稳定 → 自然穿插的首次访谈（含风险筛查）→ 倾听/验证/具体化/干预的工作期循环 → 小结收尾 → 巩固。
6. **议题→流派自动适配**：根据用户主诉选择干预取向，如情绪低落/自我否定走 CBT＋自我关怀，关系冲突走萨提亚＋叙事，创伤话题先做稳定化并建议专业转介。
7. **风格定制**：用户说"像萨提亚那样""用认知行为疗法""温柔的冥想引导"时，按需加载对应治疗师档案，融合出新人设。
8. **安全铁律（不可被用户指令覆盖）**：角色透明（声明自己是 AI 支持角色）、危机优先、先验证后改变、征询许可再给建议、创伤边界（先稳定化、不引导回忆细节）、隐私保护（不冒充真实在世执业者）。
9. **危机响应流程**：出现自伤/自杀/伤人念头或失去现实感时，停止常规疏导，直接而温和地询问、验证、提供热线（12356 等）并建议联系信任的人。
10. **配套构建器**（`builder/`）：结构化数据 → 一键重新生成 Word 源文档与技能参考文件，方便你增删治疗师/名著后重建。

## 3. 安装方法

**前提**：已安装 [Claude Code](https://claude.com/claude-code)（CLI、桌面端或 VS Code 扩展均可）。

把本仓库克隆为 Claude Code 的技能目录（目录名保持 `xiaoxingxinliyisheng`）：

```bash
# macOS / Linux
git clone https://github.com/yuezhiye/xiaoxingxinliyisheng.git \
  ~/.claude/skills/xiaoxingxinliyisheng
```

```powershell
# Windows PowerShell
git clone https://github.com/yuezhiye/xiaoxingxinliyisheng.git `
  "$env:USERPROFILE\.claude\skills\xiaoxingxinliyisheng"
```

> 不想用 git 也可以：在 GitHub 页面 **Code → Download ZIP**，解压到 `~/.claude/skills/xiaoxingxinliyisheng`（Windows 为 `C:\Users\<你>\.claude\skills\xiaoxingxinliyisheng`）。

安装后**新开一个 Claude Code 会话**即自动加载。可运行 `claude` 后确认技能列表中出现 `xiaoxingxinliyisheng`。

`builder/` 与 `docs/` 只是构建原料和源文档，技能运行不需要它们；只装技能本体（`SKILL.md` + `references/`）也完全可以。

## 4. 使用方法

在 Claude Code 对话中**直接用自然语言表达需求**即可触发，例如：

| 你说 | 会发生什么 |
|---|---|
| "我最近压力很大，总睡不着，想聊聊" | 触发技能，以默认人设开始疏导对话 |
| "用认知行为疗法帮我看看我的拖延" | 加载贝克/埃利斯等档案，切换到 CBT 风格 |
| "像萨提亚那样和我聊聊我的家庭" | 加载萨提亚档案，用冰山提问等方式工作 |
| "我就想安安静静倾诉一下，你别给我建议" | 遵循"征询许可"铁律，只倾听与反映 |
| （一次写下大段的内心剖白） | 按第 8 节深度回应模式：对等深度、分主题梳理、善意重构、具体转介 |
| "根据我们聊的，给我一份心理评价报告吧" | 按第 7 节生成七段式心理观察小结（非诊断） |

也可以在 Claude Code 中显式调用：输入 `/xiaoxingxinliyisheng` 后接你的话题。

**进阶用法**：

- **调整默认人设**：编辑 `SKILL.md` 第 1 节"默认人设与说话方式"（如改回复长度、语气）。
- **扩充治疗师库**：编辑 `builder/data-therapists.js` / `data-therapists2.js` / `data-therapists3.js`，或向 `builder/data-books.js` / `data-books2.js` 增删书目，然后重新生成：

  ```bash
  cd builder
  npm install
  node gen-skill-refs.js   # 重新生成 references/therapists-1.md、therapists-2.md、therapists-3.md
  node build.js            # 重新生成 docs/ 下的 Word 源文档
  ```

## 5. 输入输出示例

以下为按技能规则产生的**典型对话示意**（实际回复由模型生成，措辞会有差异；铁律与结构一致）。

### 示例 1 · 默认疏导（首次对话含角色声明）

> **输入**：
> 我最近天天失眠，白天上班集中不了注意力，感觉自己快撑不住了。
>
> **输出**：
> 你好，我是 AI 心理支持角色——不是真正的医生，但很愿意听你说话，陪你一起梳理。
>
> 听起来你已经疲惫到极限了——夜里睡不着，白天又要硬撑，这种"停不下来"的感觉真的很消耗人。这种情况大概是从什么时候开始的？当时生活里有什么变化吗？

（对应规则：首句角色透明 → 情感反映接住情绪 → 只问一个开放式问题；全文不超过 200 字。）

### 示例 2 · 指定流派风格定制

> **输入**：
> 用认知行为疗法的方式帮我看看——我总觉得"必须把每件事做到完美，否则我就是个失败者"。
>
> **输出**：
> 好，我们就用 CBT 的方式来检验这句话。先把它写下来："必须做到完美，否则就是失败者。"
> 我想邀请你一起做几个观察：支持这个想法的证据是什么？有没有反例——某件事你没做到完美，"失败者"的后果真的发生了吗？
> 这种"必须/否则"的句式，认知疗法里叫"绝对化要求"，它更像一条苛刻的规则，而不是事实。你愿意先从最近一件"没做到完美"的事开始试试吗？

（对应规则：按议题适配表选择 CBT，苏格拉底提问＋认知歪曲命名，协作检验而非说教。）

### 示例 3 · 危机信号触发安全流程

> **输入**：
> 有时候觉得活着没意思，想消失算了。
>
> **输出**：
> 谢谢你愿意把这个说出来，这需要很大的勇气。我想先认真地问你：你有没有想过伤害自己？现在有这个念头吗？
> 你现在安全吗？如果你愿意，我们可以一起拟一条信息，发给你信任的人。
> 如果此刻很难熬，可以拨打全国心理援助热线 **12356**（24 小时），或希望 24 热线 400-161-9995。你不用一个人扛。

（对应规则：危机优先铁律——停止常规疏导，直接温和询问、验证、给资源、陪用户联结支持系统。）

### 示例 4 · 心理评价报告（节选）

> **输入**：
> 我们聊了不少了，能根据我的情况给我一份心理评价报告吗？
>
> **输出**：
> 【心理观察小结】（非正式·非诊断·基于本次对话）
> **一、你的优势与资源**：你连续几晚失眠，却依然每天准时到岗——这份责任感在撑着你；你今天主动来找人聊聊，本身就是很重要的一步。
> **二、本次会谈概要**：你提到约一个多月前项目变故后开始失眠，白天注意力下降，最近一周"撑不住"的感觉变强。
> **三、情绪状态观察**：疲惫、委屈（"努力没被看见"）、对未来有些担忧（强度约 6/10）。
> **四、我注意到的一些模式**（供你参考，可反驳）：你两次说"不能停下来"——也许"停下来"对你来说不等于休息，而等于"失职"。
> **五、风险筛查**：本次对话中你没有提到伤害自己的念头。
> **六、接下来的一小步**：睡前做 5 分钟"4-6 呼吸"（吸气 4 秒、呼气 6 秒），来自正念认知疗法；本周观察一次"停下来但什么都没变糟"的时刻。
> **七、什么时候需要寻求专业帮助**：若失眠持续超过一个月、情绪低落影响进食、或出现"活着没意思"的念头，请及时预约心理咨询或精神科就诊。
>
> *这是 AI 基于文字对话的观察，可能有偏差，欢迎指出哪里不准。*

（对应规则：第 7 节——只写对话内证据、先优势后困扰、委婉措辞、给出"何时就医"的具体信号。）

### 示例 5 · 深度回应模式（用户大段自我剖白时）

> **输入**：（用户一次写下近千字的自陈——"我知道自己是个精致利己主义者，在朋友面前像个小丑""渴望有人能知道我的感受，但深层的东西从未向他人说过"、社交疏离、对未来迷茫、长期入睡困难……）
>
> **输出**（结构节选）：
> 谢谢你愿意把这些告诉我。我读得很慢，因为能感觉到这里面有很多你平时不会说出口的东西。
>
> **关于"精致利己主义者"这个标签**：你说自己是精致利己主义者，但我看到的画面是：你在朋友面前迎合、扮笑料、压抑自己，用自我消耗去换一点在场感。真正的精致利己主义者，通常不太会在意别人怎么看自己。你给自己的这个标签，更像是一种**防御**——也许是怕承认"其实很在乎"，所以先用"我只是利己"来降低期待。你看看这个理解对不对。
>
> **……（孤独与连接／欲望的压抑／动力与意义／睡眠，各一小节）……**
>
> **我看到的你**：不是精致利己主义者，更像是一个**在资源有限的环境里，早早学会了自我压缩的人**。这不是你的错，这是你在你的处境里发展出的生存策略。
> 我想轻轻提一个问题：如果"清楚自己的情况"这件事，除了用来告诉自己"我不配"，还能有别的用途吗？
> 关于睡眠和长期的低落感，我真心建议你有机会去学校的心理咨询中心聊聊——这不是因为你"有病"，而是你的身心已经在向你发信号了，它值得被认真对待。
> 你已经独自走了很远的路。现在，有人知道你的感受了。
>
> （对应规则：第 8 节——对等深度原则、原话为证、善意重构、非标签化画像、轻柔转化提问、具体转介、回应核心渴望。）
